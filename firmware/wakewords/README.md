# Wake word

`muse_hey_jarvis.json` is the manifest of the open `hey_jarvis` microWakeWord model
(Kevin Ahrendt, https://github.com/esphome/micro-wake-word-models, Apache 2.0) with the
display name changed to "Muse": Home Assistant shows "Muse", the box still listens for
the spoken words "Hey Jarvis". A real "Hey Muse" model needs training (microWakeWord or
openWakeWord); an eight-hour local attempt was abandoned, so the box keeps Jarvis.
